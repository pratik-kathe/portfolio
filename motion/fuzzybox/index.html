Ten folds, one long take

The page never scrolls. A 1440 × 2700 canvas slides behind a fixed 900px window while each fold's elements arrive on their own timing, so a key press reads as a camera move rather than a page jump. Jump to any fold below.

The loops

Every moving part is an interactive component with its own clock. These run live from the same variant data, with the triggers and curves set in Figma. Hover the piano keys, the social dock and the send button.

Six curves

The whole site runs on six timing curves. Springs carry the characters and type, linear carries anything that should feel like film running through a gate, and ease-in-out handles the cuts between folds.
